วิธี Setup Notion Integration (ครั้งแรก)
1
ไปที่ notion.so/my-integrations → New Integration → ตั้งชื่อ เช่น "AjarnBot" → Submit → คัดลอก Internal Integration Token
2
สร้าง Database ใน Notion (full-page database) → คลิก Share → เพิ่ม Integration ที่สร้างไว้ → คัดลอก Database ID จาก URL (notion.so/.../DATABASE_ID?v=...)
3
เพิ่ม Environment Variables ใน Railway:
NOTION_TOKEN=secret_xxx...
NOTION_DATABASE_ID=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
4
กด Setup DB เพื่อสร้าง columns ที่จำเป็น → กด Sync Now เพื่อ push ข้อมูล
